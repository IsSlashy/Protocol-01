## Standing rules (do not relearn them the expensive way)

- Never say zero-knowledge, untraceable, trustless, first, or 128 bits about
  this protocol. Devnet only. Deploy with `--program-id <pubkey>`.
- A quoted number is not a measurement. Every figure in a report comes from
  a command run in that session.
- Do not push while a CI run is in progress. Do not re-enable turbo's test
  cache without `inputs`.
- Ask before killing processes that are not yours; the founder runs other
  agents on this machine. A stopped `Monitor` leaves `tail`/`grep` orphans;
  kill those by matching your own filter text.
- Live harnesses under `Monitor`: exclude `^stdout \|` lines or the monitor
  drowns and stops (the run survives).
- Keep agent fan-out modest; write shared state to files in the scratchpad,
  not in prompts.

## Open limits, stated as they are

- The key is bearer material: whoever holds it is the customer.
- The issuer can still spend an issued note before the holder does (custody
  on issued notes), and the anonymity set against the issuer is one.
- P6 is structural (every transaction has a funded fee payer); P11 is
  measured only on harness spends today.
- The verifier's zero-knowledge argument is executed on two witnesses at
  2 queries and one at 22; grinding nonce and query-position derivation are
  unmeasured. The wording "zero-knowledge" stays forbidden.
